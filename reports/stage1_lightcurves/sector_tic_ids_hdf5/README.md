# Exact A2v1 HDF5 TIC inventories: S60--S63

These are the Selma-style one-column TIC lists: each `tic_id` in a CSV or TXT
has at least one nonzero TGLC HDF5 light curve in the completed A2v1 PDO orbit
trees for that sector. The files were generated by scanning the PDO HDF5 paths,
not inferred from the TWIRL observation table.

| Sector | Requested positive-TIC targets | Unique TICs with HDF5 | Omitted targets |
| --- | ---: | ---: | ---: |
| S60 | 27,165 | 27,036 | 129 |
| S61 | 41,403 | 41,168 | 235 |
| S62 | 40,158 | 39,964 | 194 |
| S63 | 53,512 | 53,249 | 263 |

Every omitted target is an explicit `edge_warn` observation-table exclusion;
there are no missing non-edge TICs in these four sector inventories. Duplicate
TIC filenames can occur across detector paths. Each TIC is listed once, while
the accompanying JSON sidecar records the path and duplicate counts, input
orbit roots, timestamps, and SHA-256 hashes.
